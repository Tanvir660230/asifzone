# Tahafi launch checklist

## The owner provides

- [ ] Product photos from a real shoot: front, back, detail and on-model for each product, in one warm grade, 4:5, at least 1600px tall.
- [ ] Lifestyle photos for the hero, the lookbook (3–4) and the story.
- [ ] Prices, sizes and a size chart per product (chest and length in inches), fabric and care notes.
- [ ] Fit notes for product pages (model height and the size worn).
- [ ] Delivery charges inside and outside Dhaka, the free-delivery threshold (if any), and the exchange and return rules.
- [ ] Contact email, phone, WhatsApp number, Facebook and Instagram links.
- [ ] Payment methods: cash on delivery; say whether bKash should be offered.
- [ ] SEO title and description, and the newsletter heading.

## Before ads go live

- [ ] Every sample product and photo is replaced or deactivated.
- [ ] A test COD order has gone through, from order to courier booking.
- [ ] The Meta Pixel and Conversions API are set in this store's own Settings → Integrations.
- [ ] Nightly backups are running (`/var/log/tahafi-gdrive-backup.log` shows a first OK).
- [ ] tahafi.com and www.tahafi.com both serve over HTTPS, and asifzone.com and nasihamart.com still return 200.
